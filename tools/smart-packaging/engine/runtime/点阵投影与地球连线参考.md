# 点阵投影与地球连线 · 使用参考

日期：2026-10-27
实现：`engine/runtime/globe.js`（移植自 385712 open-beta core.js L392-448，MIT；语法已校验）。
数据：`core/data/land.js`（同源，HTML 中先于 globe.js 引入，提供 `window.LAND` 陆地点阵）。

## 这是什么

不用 WebGL 的"假 3D 深空舞台"：球面投影函数 `gproj(lon,lat,rot,tilt)` 返回旋转+倾斜后的
[x,y,z]，z<0 即背面剔除。整套渲染 = 径向底光 + 经纬网格 + 陆地点云（深度驱动透明度/点径）
+ 大圆连线弧（进度描边+弧顶隆起+端点辉光）+ 地点 pin（声纳扩散环）。

## 三个直接可用的场景

1. **光环科技开场**：`globeDraw(ctx, t, {R, rot:t*0.1})` 缓慢自转 + arcs 逐条亮起 =
   规范里"星点汇聚成品牌字"的底景；arc 的 `p` 参数接场景进度。
2. **深场复盘页**：pins 标记"已认领的屏"（k 参数控制单个 pin 的透明度），扩散环天然是
   认领动效。
3. **像素海洋隐藏关**：LAND 换成自己的点阵数据（如关卡地形），globeDraw 换成正交投影
   即得 3D 感关卡全景——land.js 的替换姿势就是 `window.LAND = [[x,y],...]`。

## 调用约定

```js
fxDraw(ctx => globeDraw(ctx, t, {
  cx: 540, cy: 700, R: 380,        // 球心与半径（9:16 竖屏示例）
  rot: t * .12, tilt: -.35,        // 自转与倾角
  arcs: [[116, 40, -74, 40, p]],   // [lon1,lat1,lon2,lat2,进度,颜色?]
  pins: [[116, 40, 'BJ', null, 1]],// [lon,lat,标签,颜色?,透明度?]
}))
```

## 教训（移植时发现）

- 他的连线路径是大圆插值 ler(lon,lat) + 正弦隆起，不是贝塞尔——简单且物理感对，照抄。
- 声纳环 `(t*30 % 22)` 与全局时钟直接耦合；我们做实例化时要改成 `(t-t0)*30` 按事件原点，
  已在改造清单记录（globe.js 保持原样，场景层包一层）。
