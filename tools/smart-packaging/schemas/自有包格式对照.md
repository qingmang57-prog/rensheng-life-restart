## 规范九章（我们的对应物该有什么）

| .motion 规范章节 | 我们的对应设计 |
| --- | --- |
| 1 协议分层 | 包结构分层：manifest / 参数契约 / 内容实例 / 引擎运行时 |
| 2 开放性与互操作 | 沿用"开放契约+加密核心"可选双模；我们默认全开放 |

| 6 素材与内容适配 | mediaPorts 帧精确槽（fps×frameCount）——已在蓝图中照抄 |
| 7 运行 profile 与可复现渲染 | runtime profile 声明（fps/画幅/字体锁/色彩链） |
| 8 组件依赖与风格演进 | 组件库版本号 + 兼容声明（对标 motion-kit 0.3.0 演进） |
